Only mint what you understand, never pay more than the listed terms (value 0 for the free lot), and always preview the transaction in your own wallet before signing. MintGate never promises returns.

How to use — via your own AI agent (no login here)

There is no connect-wallet button and no login on this site — by design. Your Agentic Wallet cannot sign in through a website QR code, and MintGate never asks for your seed phrase, private key, or pairing code. You interact through your own AI agent (e.g. Binance AI Pro / Claude Code), which calls the contract — and you confirm every transaction yourself in the Binance app.

  1. Check in (once, gas only). Ask your agent to call checkIn on the MintGate contract with the keccak256 hash of your own .ai name. One check-in per wallet.
  2. Reserve a slot (gas only). Ask your agent to call reserveSlot(mintId) for the mint you want. One slot per wallet per mint. The reservation itself is free.
  3. Mint on the listed contract (value 0 for the free lot). Ask your agent to call the mint's function (see table below) with value 0, and preview it first. Only mint while the value stays 0.

Example prompt for your agent:

Call checkIn on MintGate (0x6254543dB7C211369E988BEd8ec7C82fdb89FBfc, BNB Chain)
with the keccak256 hash of my Agent ID name "YOURNAME.ai".
Then call reserveSlot(0) for Worldygg Tree.
Show me the exact calldata and the simulation result before I confirm anything.
Do not send any transaction without my confirmation in the Binance app.

Your agent needs the contract ABI — it is embedded on this page (see “Full ABI” above) and in the repo (build/MintGate.abi.json).

What the contract can and cannot do

  • Owner can: register / activate / deactivate mint listings, transfer or renounce ownership. That is all.
  • Owner cannot: touch user funds (the contract has no payable function and can never hold BNB), mint or freeze anything, pause your check-in, or change any fee — there is no fee.
  • Agent ID is used only as an access gate (balanceOf >= 1). MintGate never looks up or displays anyone else's wallet by name.
  • No returns are promised. A free mint is a free NFT, not income.
